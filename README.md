# Hunter-gatherer Evolution and Transition

This repository contains the analysis scripts accompanying the manuscript:

**Rapid convergence toward an agriculturalist regulatory landscape following lifestyle transition in Bornean hunter-gatherers**

*Kusuma et al. in bioRxiv doi: 10.64898/2026.08.09.743820*
---

## Overview

We profiled transcriptomic and epigenomic variation across three population groups from Borneo — **Punan Batu** (hunter-gatherers), **Punan Tubu** (transitioned hunter-gatherers), and **Lundayeh** (agriculturalists) — to investigate the molecular signatures of lifestyle transitions. Analyses include differential gene expression, differential methylation, cell-type deconvolution, gene co-expression network analysis, and phenotype-based classification.
